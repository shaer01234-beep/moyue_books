# 项目截图

将应用截图放置于本目录，README 中的「项目截图」章节会自动引用以下文件：

| 文件名 | 说明 |
|--------|------|
| `bookshelf.png` | 书架视图（网格 / 列表） |
| `reader.png` | 在线阅读器（EPUB 阅读界面） |
| `edit.png` | 导入与编辑图书信息 |
| `settings.png` | 设置（阅读偏好、账户、TTS 等） |

建议：

- 格式 PNG，宽度约 1200px，单张不超过 1MB。
- 命名与 README 中的引用保持一致；新增截图请同步更新 README 表格。
- 不要包含个人隐私图书或敏感内容。
